# Four independent motion experiences — review storyboard

The approved educational architecture is retained. Each section has its own clock, controls and inspection state. Times below are authored playback durations, not runtime performance or execution timing. Nothing starts on scroll, loops in idle, or automatically moves the visitor to another section. Any stage can be selected directly.

## Native Core — precision and authority boundaries

Visible task: **Inspect this project and identify potential issues.** A source-grounded simplified inspect path is illustrated; other operations may take different paths. Source detail is in `SOURCE-NOTES.md`.

| Clock | Choreography | Meaning / inspector |
| --- | --- | --- |
| 0–2.5s | Request packet leaves Desktop toward the typed client; path draws behind it. | User text plus a registered workspace identity; no authority in the renderer. |
| 2.5–5s | Client → broker. | A supported typed intent crosses a local process boundary, not a shell command. |
| 5–7.5s | Broker → Registry. | Supported workflow preparation needs compatible configuration. |
| 7.5–10s | Registry → daemon/kernel responsibility. | Resolved configuration is captured; acceptance/workspace binding/authorization remain native checks. |
| 10–12.5s | Authorized boundary → provider communication. | A permitted provider turn can propose work; the proposal is still untrusted. |
| 12.5–15s | Response packet returns toward the native tool gate. | Fixed catalog, strict arguments and limits; the Kernel independently authorizes supported read tools. |
| 15–17.5s | Recording path forms toward journal/task state. | Record what was attempted, without inventing findings or verified success. |
| 17.5–20s | Bounded response returns to broker. | Only supported client-owned run information is exposed. |
| 20–22.5s | Response arrives back at Desktop, then holds. | UI displays known state or explicit refusal. It does not own execution authority. |

Purple request, blue response, dashed green recording and red refusal are also labeled in text. Nodes receive clock-derived depth emphasis; the packet and SVG path reveal direction. The operation/evidence panel follows the active boundary while the detailed responsibility inspector remains available.

The optional denied variant illustrates an unsupported/mutating tool proposal in read-only inspection. It is refused at the tool gate and the refusal is preserved in the response. No actual tool, provider or project is invoked. Clicking/focusing a mapped boundary seeks its corresponding stage and pauses; CLI remains a separately inspectable entry.
