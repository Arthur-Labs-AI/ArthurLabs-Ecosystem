## Motion controller contract

Every feature owns an instance of a local GSAP timeline through a reusable hook. Timeline progress is the single animation clock. React renders geometry from that clock; no CSS transition competes for those transforms. State: idle/playing/paused/inspecting/completed. Controls: explicit start/resume, pause, replay, previous/next and direct step selection. Seeking pauses. Inspection pauses. No scroll triggers, autoplay, auto restart or loops. Reduced motion uses manual settled stages; start explains and shows a settled stage without automatically cycling text. Media changes stop movement. Timelines are killed on unmount. Motion keeps captions and controls in normal document flow, not covering diagrams.

## Architecture review

1. Truth: GSAP scalar clock per demo; typed authored data; existing release catalog for distribution.
2. Ownership: local hook writes its clock and lifecycle; each feature owns inspection/filter inputs. Derived positions and step selection never compete with it.
3. Dependency direction: route → feature/download components → reusable motion hook + stable content/math. No application imports.
4. Contracts: serializable release metadata and authored stage arrays. No live engine state, credentials or process handles.
5. Failures: empty/invalid/withdrawn release records produce no enabled link. JS-free page keeps educational text/default scenes/download status readable.
6. Lifecycle: instantiate paused; explicitly play; pause/seek/inspect; complete; replay; kill on unmount. Preference changes pause; no timers while idle.
7. Test seams: DOM progress/state attributes; real-time timeline samples, SVG geometry/transforms/dashes; release predicate accepts catalog fixtures.
8. Compatibility: Landing/Suite/main Nexus untouched. Existing inspectors and tests retained; source hashes compare protected files. Only concept-specific files change.
9. Observability: data-motion and data-progress/state, textual phase readout, individual exclusion/refusal explanations. No telemetry.
10. Security: inert examples only; only metadata-verified HTTPS download links enabled. No shell, provider calls, installer creation, application writes or claimed release availability.
