## Ten architecture answers
1. Source of truth: existing hook owns each demonstration clock; existing catalog/guard owns downloadable metadata; inspected source owns factual copy.
2. Ownership: product composition reads reusable demos; optional presentation props default false. Product navigation owns only its menu state.
3. Direction: route → product presentation / existing feature components → existing motion/data. Features never import the product route. Scoped guides consume explicit props.
4. Contracts: optional productPage booleans and guide values; no application IPC, runtime or persistence crosses into the website.
5. Failures: absent artifact metadata stays unavailable; unverified platform remains unconfirmed. No remote request is needed to render the product or explanations.
6. Lifecycle: reuse existing animation cleanup. Menu listeners remove on unmount; navigation closes and focuses destination without animation when reduced motion is requested.
7. Tests: actual browser state/progress and SVG geometry; manual controls and reduced-motion equivalents; injected release metadata tests already retained.
8. Compatibility: preserve concept default props and all original motion code. Static /nexus supersedes the generic foundation; Studio/Sentry stay generic. Rollback removes static route/product module and optional presentation additions.
9. Observability: existing data-motion/progress/state hooks, visible availability and planned/restricted labels; browser errors and capture evidence.
10. Security: no providers, installer generation, tools or application processes. Source inspection is read-only. Download guards remain authoritative. Public source links do not imply native binaries are released.
