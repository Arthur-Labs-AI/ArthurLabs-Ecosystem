A warm editorial environment rather than an engineering explanation. The headline is “A home for unfinished ideas.” The two hero actions are genuine native anchor links; download resolves to an honest development state. The desk supports discovery in any order.

## Visual system

Paper `#F4EEE5`; linen `#DCCCB9`; clay `#A77D68`; sage `#6C7565`; ink `#342D2A`. Studio's own bundled Newsreader (regular/italic variable) and Hanken Grotesk establish continuity with the real application. Licensed OFL copies are namespaced to this route. No external font request.

Display type is warm, large and purposeful: an upright opening line followed by an italic second line. Small uppercase marginal captions, hairlines, handwritten-style serif annotations and restrained directional icons create print-like rhythm. Paper textures are fine, static CSS lines; shadows suggest physical contact without a heavy 3D engine. The existing global glass navigation is preserved as approved.

## Motion language

CSS owns static placement/rotation. Dedicated GSAP layers own pointer parallax, sibling recession and one flight surface. Selecting an object creates a geometric continuation: 180ms lift, then 800ms expansion/straightening, readable details joining late. Typography and padding interpolate from the source surface rather than snapping to inspection styles. Closing interrupts safely from the actual current transform and returns over 700ms to the measured source geometry. No idle loop or wheel listener. Parallax is a bounded pointer effect only on large, hover-capable screens and stops after settling.

The native dialog provides modal semantics, inert background and focus containment. Return/Escape restore the selecting object. Resize or a changed motion preference closes safely. Reduced motion uses the same inspection content and controls without spatial travel or parallax. Native page scrolling resumes after return. An always available “Prefer to read?” collection provides an alternative and works without JavaScript.

## Responsive composition

Desktop 1440/1920 uses a generous shallow-perspective canvas and asymmetric overlaps. Tablet uses two staggered columns and reduced depth. Phone 390 is a tall, intentionally staggered arrangement with readable paper surfaces, not a scaled-down desktop. 320 is independently checked for overflow/usability. Mobile inspection is full width and vertically scrollable, with a sticky Return control. Interface inspection remains native aspect and never exceeds the original 1616px raster width.
