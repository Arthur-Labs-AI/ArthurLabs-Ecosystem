## Architecture review

1. Source of truth: typed desk data owns sample text/capability labels; existing eligibleArtifacts owns download eligibility. One hook owns inspection phase and timeline; only local draft wording state is editable.
2. Ownership: React owns selected object/draft, GSAP owns animation transforms on dedicated flight/recession/parallax layers. CSS owns static slot rotation/positions; they never write the same transforms.
3. Dependency direction: route → composition/content → desk/data/motion. Shared infrastructure is consumed, not modified; no application code imported.
4. Boundaries: typed object IDs and sample strings. No IPC, app stores, live model calls, real user data or provider credentials cross into website.
5. Failures: no eligible artifact → clear unavailable state. JS disabled → readable nonspatial details and genuine screenshot. Font fallback → serif/sans. No native dialog enhancement → nonspatial content remains available. Screenshot is existing local asset.
6. Lifecycle: idle → lifting → opening → open → closing → idle; guarded selection, kill old timeline on close, Escape allowed during transitions. Resize/motion-preference changes settle safely; cleanup kills timelines and clears temporary styles. Native scrolling is untouched outside inspection. Dialog contains its own overflow normally.
7. Test seams: data-motion and data-object markers expose phases; real matrices and bounds sampled by Playwright. Artifact recordings use actual interactions, no simulated endpoints.
8. Compatibility: additive concept route; existing static `/studio` remains generated by `[product]`. No shared style/header/catalog edits. Rollback is removal of new route/components/assets/tests, no migration.
9. Observability: explicit motion phase/selected ID, accessible status messages, browser error capture, timed transforms and visual evidence.
10. Security: browser-only fictional content. Length-bounded local edit, no HTML injection, no persistence/network. Native dialog provides focus containment; same-origin anchors lead to metadata-driven downloads.
