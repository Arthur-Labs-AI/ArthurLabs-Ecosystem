- The complete 109-test run before final fixes recorded **107 passed, 2 failed** (`full-before-final-fixes.log`). One failure was a real first-keyboard-activation race: the initial pathname effect could dismiss the newly opened disclosure. The regression now releases those scripts, focuses the enabled trigger and verifies the first Enter opens the panel.

The DPR2 test now branches on the actual config: original exports must have exact authentic filenames and native dimensions, correct aspect ratio and no CSS upscaling beyond source width; optimized mode still requires the original source and q=90. No image/application source or deployment config was changed to make the assertion pass.
